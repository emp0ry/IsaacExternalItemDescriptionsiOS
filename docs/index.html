Question-mark collectibles stay hidden, including Curse of the Blind. Visible active items left after swapping can still be described. Card visibility follows native shop, Options and reachability rules. Unidentified pills never reveal their effects.

More run-aware details

Dice Rooms, live Sacrifice Room steps, Sanguine Bond, Greed-mode changes, collection-page reminders, save-aware unlock hints, PHD / False PHD, Wild Card, Vurp!, The Stars?, Black Feather, duplicate-item and charging interactions.

Three independent spoiler controls

RNG predictions, exact Void / Black Rune stat previews and hidden current effects are independent switches, all off by default. Spindown’s deterministic ID chain is not gated by the RNG switch.

Getting started

Install. Restart.
Approach a pickup.

No Steam account or separate database generation is needed.

A

Rootless jailbreak

  1. Install IsaacExternalItemDescriptions-rootless.deb with your package manager.
  2. Make sure ElleKit is available. Remove duplicate EID loaders.
  3. Fully restart Isaac. Approach an eligible pickup in a run.
B

LiveContainer

  1. Extract the LiveContainer.framework.zip archive.
  2. Import the framework into an app-specific Tweak Folder and assign it to Isaac. Do not use Global Tweaks.
  3. Fully restart the guest app. Fonts and descriptions are already inside the framework.
C

Direct embedding

  1. Use the Embedded package, containing the dylib and complete IsaacEID.bundle.
  2. Use the project’s IPA patcher or your existing embedding workflow.
  3. Sign the modified dylib and complete app bundle, then install and restart.

Good to know

Clear information.
Clear limits.

Is this the complete desktop EID mod?

No. It brings original EID descriptions, fonts and many contextual features to native iOS. General crafting recipe search, every co-op/subplayer rule, arbitrary Lua callbacks and every prediction are not implemented. One nearby eligible description is shown at a time.

Does it work without a jailbreak?

The dylib uses public iOS frameworks and has no jailbreak-only library dependency. LiveContainer and signed embedding are provided. Direct embedding still requires code-signing the complete application; this is not an App Store app.

Does it reveal hidden items or modify saves?

Hidden-item protection is retained. Browsing descriptions is read-only: it does not activate items, unlock achievements, advance game RNG or edit save files. The three optional spoiler controls start off unless you have explicitly saved a different preference.

Are the descriptions in the game’s language?

You choose EID’s language independently. Its settings and inventory follow that choice; missing description translations fall back to English. Position, size, width and opacity are adjustable, and each slider has its own reset.

Is Isaac, DLC or Debug Console included?

No game IPA, executable, save, extracted game artwork or purchase bypass is distributed. Game item artwork is read from the installed game. Console is a separate mod, visible in some supplied screenshots but not part of EID.

What if something looks wrong?

First restart Isaac and check that only one EID copy is loaded with its matching resources. Include your game version, loading method, item ID and a screenshot in a GitHub issue. Every character, language and device combination has not been exhaustively replayed.
