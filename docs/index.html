Features

The information you need, right in the room.

An EID experience adapted to the native iOS game, from nearby pickups to the next Sacrifice Room payout.

Reroll and absorption previews

See eligible Spindown results, separate Void/Black Rune stat predictions, and native Flip alternates. Blank Card, Clear Rune, and Placebo show supported mimic charge costs.

Live chances and trinket bonuses

Supported effects show their chance at your current Luck. Golden trinkets and Mom's Box use the original per-trinket bonus rules.

Collection and pill context

Find collectibles still missing from your save's collection page. PHD and False PHD descriptions follow the current player's pill effects and applicable rewards, including horse pills.

Nearby item descriptions

Collectibles, trinkets, cards, runes, identified pills, and Crane Game prizes follow the player and the nearest eligible object.

Room effects

See all six Dice Room effects and the next Sacrifice Room payout, with the current step from 1/12 through 12/12.

Transformation progress

Live item ownership and persisted counters keep progress current through pickups, item replacement, and reloads, including pill transformations and counts above 3/3.

Pause inventory

Pause and open EID Items. Selected descriptions always have a readable dark background. Select D Infinity, then tap its description to browse all ten dice with a top-right 0/10 › counter, without changing the game's active item.

Make it yours

Choose among 20 languages and adjust position, scale, opacity, name, icon, quality, and description visibility in EID ⚙. The optional gameplay background fits the title and text; pause selections use a temporary readable backdrop without changing your settings.

Knowledge-aware display

Native pill knowledge, Curse of the Blind, card visibility, and pickup reachability determine which descriptions should appear.

Character context

Lost/Keeper warnings, health-type replacements, Birthright bonuses, Book of Virtues wisps, and Tainted Cain salvage information adapt supported descriptions to your character.

Synergies and weapon warnings

Car Battery and Tarot Cloth show changed effects. Weapon override warnings explain when a pickup replaces an owned weapon or is overridden by it.

Floor and reward previews

Pandora's Box highlights this floor's payout. Consolation Prize previews its stat and consumable candidates, while Greed mode uses its own conditional descriptions.

Usage

Install once. Read as you play.

Back up Isaac’s application data before replacing or re-signing an installation. The release contains the mod and its resources; use your own copy of the game.

01

Choose your format

Install the rootless DEB with a package manager, import the framework into a LiveContainer private app, or embed the complete package into the app bundle.

02

Restart Isaac

The nearest eligible description appears during a run. Artwork and item information disappear together after the item is collected.

03

Tune the overlay

Open EID ⚙ from a menu or while paused. Tap EID Items during a paused run to browse the current inventory.

Requirements & credits

Built for native Repentance.

The current release supports the ARM64 App Store 1.4 executable with Repentance v1.7.9b.J754. A game update may require native-layout revalidation.

Supported game

Bundle identifier com.Nicalis.Isaac-iOS, App Store version 1.4, Repentance v1.7.9b.J754.

Installation options

Rootless injection uses ElleKit. The core dylib also supports LiveContainer private apps and direct embedding.

Verified executable

An unknown Mach-O UUID disables the overlay before game entities are scanned.

Original EID credits

Descriptions, translations, markup, and visual resources are credited to wofsauge and the External Item Descriptions contributors.
