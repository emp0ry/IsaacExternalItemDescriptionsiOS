GETTING STARTED

The right format
The complete bundle.

Choose the package for your own installation. Back up application data before changing or signing it.

Full installation guide ↗
  1. Install the DEB.

    Use a compatible rootless package manager. It includes the required resource bundle.

  2. Restart Isaac.

    Fully close and reopen the game after installation or update.

  1. Use a private app.

    Create an app-specific tweak folder for Isaac; do not use Global Tweaks.

  2. Import the framework.

    Import the released framework into that folder and keep TweakLoader enabled. Follow the installation guide for signing.

  3. Restart completely.

    Select the folder for Isaac, then fully close and reopen it.

  1. Get both pieces.

    Use the matching Embedded ZIP for the resource bundle. PlayCover needs the separate platform-specific dylib.

  2. Embed and sign.

    Preserve the complete IsaacEID.bundle and use the documented load path. Sign the complete application correctly.

  3. Restart and verify.

    Use one library copy. Keep other independent mods intact.

One copy and one loading method. The resource bundle must match the library. Re-signing can affect the app container, Keychain, receipts and access to purchased DLC.

A LITTLE MORE CONTEXT

Good to know.

Does it reveal unknown pills or Curse of the Blind?+

Their protections remain. Optional spoiler-related previews are separate settings and default off.

Does the PlayCover dylib contain the resources?+

No. Obtain the complete matching IsaacEID.bundle from the Embedded ZIP and follow the installation guide.

Is this the complete desktop EID mod?+

No. The parity document describes the native adaptation and remaining scope. The original Lua mod and this bridge are distinct projects.
